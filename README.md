# lern-github
ฉันชื่อนางสาวฟาตีเมาะห์ เด็ง หรือเรียกสั้นๆว่าครูฟาติน คณะศึกษาศาสตร์ สาขาวิชาเทคโนโลยีสารสนเทศและการประเมินทางการศึกษา เป็นนักศึกษาปฏิบัติการสอนในรายวิชาเทคโนโลยี(วิทยาการคำนวณ)2 สอนในรายวิชาเทคโนโลยี(วิทยาการคำนวณ)2 สอนระดับชั้นมัธยมศึกษาปีที่ 4 โรงเรียนสาธิตมหาวิทยาลัยสงขลานครินทร์(ฝ่ายมัธยมศึกษา) โต๊ะทำงานจะอยู่ที่ห้องหมวดวิทยาศาสตร์และเทคโนโลยี.
